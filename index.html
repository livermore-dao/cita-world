全屏模式

导入词库支持 .pdf / .docx / .csv / .tsv / .txt / .md——转换工具已内置在页面里，选文件后先弹出转换预览，逐条确认再导入。
PDF 首次解析需联网（加载开源解析库，之后可离线）；Word 与文本格式完全离线；扫描版 / 拍照版 PDF 需先 OCR。

导入的词库与错词记录会保存在本机浏览器，下次打开自动恢复，无需重复导入。
换电脑、换浏览器或清理浏览器数据前，建议先导出备份：词库导出为 CSV，错词本导出为 CSV，之后可用「导入错词本备份」还原（会与现有记录合并）。

「导出全部存档」把所有用户连错词记录打包成一个 JSON，换设备或清缓存前建议先导出。
